# Server Log Analyzer

ابزاری ساده با Python برای خواندن و تحلیل فایل‌های Log سرور.

این برنامه اطلاعات ثبت‌شده در فایل Log را بررسی می‌کند و گزارشی از تعداد درخواست‌ها، کدهای HTTP، IPهای پرتکرار و درخواست‌های کند ارائه می‌دهد.

## امکانات

- خواندن فایل Log به‌صورت خط‌به‌خط
- شمارش درخواست‌های HTTP
- دسته‌بندی کدهای وضعیت HTTP
- شناسایی IPهای پرتکرار
- شناسایی درخواست‌های با زمان پاسخ بیشتر از یک ثانیه
- تشخیص خطوط دارای اطلاعات نامعتبر
- مدیریت خطای پیدا نشدن فایل

## تکنولوژی‌های استفاده‌شده

- Python 3
- File Handling
- List و Dictionary
- `enumerate()`
- `split()` و `strip()`
- `sorted()`
- `try/except`

## پیش‌نیازها

- نصب Python 3

این پروژه فقط از قابلیت‌ها و کتابخانه‌های داخلی Python استفاده می‌کند.

## نحوه اجرا

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/USERNAME/python-server-log-analyzer.git
```

وارد پوشه پروژه شوید:

```bash
cd python-server-log-analyzer
```

برنامه را اجرا کنید:

```bash
python3 main.py
```

نام فایل ورودی را وارد کنید:

```text
access.log
```

python-server-log-analyzer/

## قالب فایل ورودی

هر خط از فایل Log باید شامل شش بخش باشد:

```text
timestamp | ip | method | path | status | response_time
```

برای مثال:

```text
2026-11-08 10:15:00 | 192.168.1.10 | GET | /login | 200 | 0.24
```

## اطلاعات گزارش

برنامه موارد زیر را تحلیل می‌کند:

- تعداد کل درخواست‌ها
- تعداد هر کد HTTP
- پنج IP با بیشترین تعداد درخواست
- درخواست‌هایی که بیشتر از یک ثانیه طول کشیده‌اند

## محدودیت‌ها

- فایل ورودی باید از قالب مشخص‌شده پیروی کند.
- این نسخه مستقیماً به وب‌سرور متصل نمی‌شود.
- تحلیل فقط روی اطلاعات موجود در فایل انجام می‌شود.
- آستانه تشخیص درخواست کند در نسخه فعلی یک ثانیه است.

## هدف آموزشی

این پروژه برای تمرین خواندن فایل، پردازش داده‌های متنی، استفاده از Dictionary برای شمارش اطلاعات و تولید گزارش کاربردی طراحی شده است.

تحلیل Log یکی از مهارت‌های مفید در بررسی مشکلات سرویس‌ها، سرورها و زیرساخت شبکه است.
